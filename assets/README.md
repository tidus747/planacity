# Design originals

Keep editable logo and graphic originals here (for example, SVG or design files).
Store only originals that are useful to future contributors; avoid large exports
or temporary design iterations.

Export desktop runtime assets to `src/planacity/resources/icons/` or `images/`.
Export website assets to `website/public/icons/` or `website/public/images/`.
Record attribution and license details alongside any third-party assets.
