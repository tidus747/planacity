# Example program

The v0.1 sample will be **Aurora Test Bench**, a fictional engineering program:

- A six-week planning horizon, not a hardcoded quarter.
- Integration and Validation WorkGroups, each with an Epic.
- Tasks and Subtasks with estimates in hours and explicit dates.
- Three fictional people and a small set of related/dependent work items.

The sample must open through the normal project workflow and survive save/reopen.
Create the actual data after the canonical model and project file format are
implemented (issue V01-11 in `docs/v0.1-issues.md`). There is deliberately no
invented JSON format or real corporate data here.
