PLANACITY WINDOWS PREVIEW

Planacity is an open-source program planning workspace for engineering teams.
This portable build is an early development preview intended for feedback.

START

1. Extract the complete ZIP to a normal local folder.
2. Keep every file in the Planacity folder together.
3. Run Planacity.exe.

No Python installation, account, or network connection is required after the
ZIP has been downloaded.

WINDOWS SECURITY NOTICE

This preview is not code-signed. Windows SmartScreen may show an unknown
publisher warning. Run it only when downloaded from the official Planacity
GitHub Releases page and after checking the published SHA-256 checksum. Do not
disable SmartScreen globally.

LOCAL DATA

Planacity does not upload planning data. Project files and JSON backups are
stored only in the locations you choose in the Save and Export dialogs.
Appearance and local UI preferences are stored in your Windows user profile.

FIRST STEPS

The examples folder contains the fictional Moon Heist backup. In Planacity,
choose File -> Restore JSON backup... and open:

    examples\moon-heist.planacity.json

Then choose File -> Save As... before experimenting with your own copy.
