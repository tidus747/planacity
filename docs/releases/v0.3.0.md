# Planacity v0.3.0 - Visual Planning

Prepared release notes. This document does not publish a release or tag.

Planacity now lets you explore and adjust a program visually using the same
local plan that powers the Plan spreadsheet and Jira roundtrip.

## What you can do

- View scheduled bars with day, ISO-week, and calendar-month scales.
- Group by hierarchy, Epic, or WorkGroup, and combine title, type, WorkGroup,
  and schedule-state filters. Standalone and ungrouped work stay visible.
- Read directional dependency arrows and accessible relationship details.
  Cycles, incomplete dates, and hidden endpoints have explicit explanations.
- Resize bar edges with day snapping, original/proposed date previews, and
  cancellation. Edit dates using the keyboard or the themed calendar controls.
- Keep effort hours, other work, and imported Jira baselines intact while dates
  change. Save, reopen, and continue working with the updated plan.
- Use light or dark appearance with readable calendar cells and visible handles.

Try the expanded [Aurora example](../../examples/README.md) and
[getting-started walkthrough](../getting-started.md). Real Timeline screenshots
show both appearances, grouped work, and an active resize preview.

## Compatibility and boundaries

Requires Python 3.11+ and PySide6. Wheel and source distributions require a Python
environment; they are not standalone desktop installers. Windows is the initial
desktop target. Automated Linux checks use Qt's offscreen platform and do not
constitute a manual Linux desktop usability review.

The project format remains schema 2. Schema 1 backups and projects remain
readable; preserve a backup if returning to v0.1. No Jira API or cloud connection
is required. Planning data stays local.

Person grouping requires the separate Allocation model planned for v0.4. Roster
entries and Jira assignee metadata are not allocations. Milestone markers require
first-class Milestones in v0.6; zero-duration tasks are not used as substitutes.

No automatic scheduling, capacity calculations, whole-bar moving, drag-edge
auto-scrolling, undo framework, Timeline export, or standalone installer is added.
Scroll before resizing, or use Edit dates for dates beyond the visible area.
Dependency arrows require both actual endpoints on screen and can be toggled off.
